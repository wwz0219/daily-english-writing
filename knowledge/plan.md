# 每日英文作文練習與批改工具計畫

## 願景

在聊天中建立一套簡單、可持續的英文寫作練習流程：每天收到寫作提醒與短文題目，直接在聊天提交作文，並獲得清楚的批改、修正版和依個人弱點調整的學習建議。透過每日練習逐步改善文法、用字、句子結構與表達流暢度。

## 路線圖與目前狀態

目前已準備每日晚上 8:00（台北時間）的提醒卡片，提醒內容包含 100–150 字短文題目，並要求在本聊天回覆作文。提醒工具回報卡片已呈現在 App；如畫面要求確認，仍需點選卡片啟用。已建立 GitHub repository 並將靜態網站和 Pages Actions workflow 推送到 `main`；GitHub Pages 設定與首次部署仍待確認。批改流程已在本聊天約定，尚待實際提交作文後持續使用與調整。

## 每日使用流程

1. 每晚 8:00（台北時間）收到一個英文短文題目。
2. 在本聊天回覆約 100–150 字的英文作文。
3. 取得修正版、主要錯誤說明及具體練習建議。
4. 依據常見錯誤，將下一次練習重點聚焦在最需要加強的能力。
